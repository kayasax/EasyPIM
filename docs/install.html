Install the EasyPIM modules for your PIM automation stage

Use the Core module for daily Microsoft Entra PIM and Azure RBAC operations. Add EasyPIM.Orchestrator when you are ready to manage privileged access from reviewed JSON configuration.

Core module

Bulk operations first

Install EasyPIM to export policies, manage eligible assignments, and automate routine privileged access work.

Orchestrator module

Policy-as-code next

Install EasyPIM.Orchestrator when configuration files, drift checks, and deployment modes belong in your change process.

Install commands

Choose PowerShellGet or PSResourceGet below. Both install from PowerShell Gallery for your current user, without requiring an elevated shell.

Prerequisites

  • Use a supported PowerShell 7 release, or Windows PowerShell 5.1. Ensure your shell meets the requirements of the current package dependencies.
  • Allow network access to PowerShell Gallery. Use PowerShellGet for Install-Module, or Microsoft.PowerShell.PSResourceGet for Install-PSResource.
  • The package manager installs required modules, including Az.Accounts and Microsoft.Graph.Authentication. Orchestrator also depends on EasyPIM.
  • Installation does not grant tenant access. Before running PIM commands, confirm licensing, authentication, and permissions for your target scope in the EasyPIM documentation.

Install EasyPIM Core

Start here for assignment lifecycle management, policy exports, backups, restores, and role policy updates.

With PowerShellGet:

Install-Module -Name EasyPIM -Repository PSGallery -Scope CurrentUser
Import-Module EasyPIM

Or with PSResourceGet:

Install-PSResource -Name EasyPIM -Repository PSGallery -Scope CurrentUser
Import-Module EasyPIM

Open the EasyPIM PowerShell Gallery package

Install EasyPIM.Orchestrator

Add the orchestrator when you want JSON templates, WhatIf previews, delta mode, and drift detection.

With PowerShellGet:

Install-Module -Name EasyPIM.Orchestrator -Repository PSGallery -Scope CurrentUser
Import-Module EasyPIM.Orchestrator

Or with PSResourceGet:

Install-PSResource -Name EasyPIM.Orchestrator -Repository PSGallery -Scope CurrentUser
Import-Module EasyPIM.Orchestrator

Open the EasyPIM.Orchestrator PowerShell Gallery package

Verify before production

Confirm the module imports, list available commands, and run previews in a non-production tenant before changing live access.

Get-Command -Module EasyPIM
Get-Command -Module EasyPIM.Orchestrator
Get-Help Invoke-EasyPIMOrchestrator -Examples

Which module should I install?

Choose Core for operational fixes

Use EasyPIM when you need to export current state, add or remove assignments, copy role settings, or standardize manual PIM tasks.

Choose Orchestrator for governed rollout

Use EasyPIM.Orchestrator when reviewers expect a file-based model, predictable previews, and drift reports before enforcement.

Use both for staged adoption

Start with Core to baseline and clean up, then promote stable requirements into orchestrator templates. Follow the project documentation for authentication and command reference.
